# chenguang-agent

#### 介绍
《辰光Agent平台》是企业内部整合、管理各种大模型与Agent的基础平台。重点功能：
1. 基于RBAC用户权限配置
2. 各厂商模型整合配置
3. Agent配置、提示词模板
4. 模型 & Agent 功能测试页
